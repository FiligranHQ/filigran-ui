<h2>How to use this combobox</h2>
<h3>Props</h3>

| Name              | Type                              | Default   | Description                                                                                              |
| ----------------- | --------------------------------- | --------- | -------------------------------------------------------------------------------------------------------- |
| **dataTab**       | _T[]_                             | `[]`      | This is the data to display in the combobox.                                                             |
| **order**         | _string_                          | -         | The title when the combobox is closed.                                                                   |
| **placeholder**   | _string_                          | -         | The placeholder of the search input inside the popover.                                                  |
| **emptyCommand**  | _string_                          | -         | The displayed string when the input value does not fit the possibilities.                                |
| **onValueChange** | _(value: T \| undefined) => void_ | -         | The triggered function when a value is chosen, or with `undefined` when reset.                           |
| **onInputChange** | _(value: string) => void_         | -         | The triggered function when the input changes. Also called with an empty string when the popover closes. |
| **value**         | _T_                               | -         | The selected item.                                                                                       |
| **keyValue**      | _keyof T_                         | `'value'` | The key in `dataTab` that corresponds to the value field.                                                |
| **keyLabel**      | _keyof T_                         | `'label'` | The key in `dataTab` that corresponds to the label field.                                                |
| **shouldFilter**  | _boolean_                         | `true`    | Set to `false` to disable client-side filtering and search server-side.                                  |
| **disabled**      | _boolean_                         | -         | Disables the combobox trigger.                                                                           |
